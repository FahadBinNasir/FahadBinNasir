### 🚀 About Me

Software Engineering undergraduate focused on full-stack and AI/ML development, with hands-on experience building secure web, mobile, computer vision, and IoT systems.

🔭 &nbsp;I'm currently working on **Unified Knowledge Brain, an enterprise RAG platform for secure multi-source knowledge retrieval, PII protection, role-based access control, and real-time data ingestion.**  
🌱 &nbsp;I'm currently learning **MLOps, information security, RAG evaluation, and production practices for scalable AI-powered systems.**  
👯 &nbsp;I'm looking to collaborate on **Open-source projects in AI/ML, full-stack development, developer tools, and intelligent applications.**  
🤔 &nbsp;I'm looking for help with **Production RAG evaluation, observability, scalable MLOps pipelines, and reliable deployment of AI-powered systems.**  
💬 &nbsp;Ask me about **Python, FastAPI, Next.js, TypeScript, Flutter, REST APIs, RAG systems, computer vision, and applied AI/ML.**  
⚡ &nbsp;Fun fact: **I enjoy turning university projects into working products, from AI and computer vision systems to Flutter apps, IoT devices, and game prototypes.**

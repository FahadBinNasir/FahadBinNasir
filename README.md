## Featured Projects

### Unified Knowledge Brain

**Secure Multi-Tenant Enterprise RAG Platform | Final Year Project**

Enterprise knowledge platform for securely ingesting, protecting, retrieving, and querying organizational data across multiple external services using tenant-isolated retrieval and role/clearance-based access control.

<p align="center">
  <img src="https://fahad-readme-assets.authentiq-integrity.workers.dev/unified-knowledge-brain-architecture.svg" width="100%" alt="Unified Knowledge Brain Architecture" />
</p>

- Built with **Python 3.11**, **FastAPI**, **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, **PostgreSQL 16**, **pgvector**, and **Redis 7**.
- Supports **6 connector families:** GitHub, Slack, Gmail, Google Drive, Dropbox, and Zendesk.
- Implements **3 roles** and **5 clearance levels:** Public, Internal, Confidential, Restricted, and Top Secret.
- Uses **Microsoft Presidio**, regex secret detection, classification, masking, and pre-storage scrubbing for security-first ingestion.
- Provides **PostgreSQL + pgvector** retrieval with tenant, clearance, and metadata filtering.
- Integrates **Groq** for LLM-assisted answers with retrieved document citations and risk analysis.
- Uses **Nango** for OAuth connection flows, provider proxy calls, and webhook delivery.
- Includes **SSE** streams for observability logs, Slack live updates, and connector activity.
- Uses **Fernet encryption** for connector credentials and secret-provider abstraction through Infisical or AWS Secrets Manager.
- Defines AWS-ready infrastructure with **Docker Compose**, **Caddy**, **Pulumi**, EC2, VPC, IAM, CloudWatch, Secrets Manager, and encrypted EBS.
- Includes **20 backend test files** with approximately **121 pytest tests**.

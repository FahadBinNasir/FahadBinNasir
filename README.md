#### Architecture

<p align="center">
  <img
    src="./assets/unified-knowledge-brain-architecture.png"
    width="100%"
    alt="Unified Knowledge Brain Architecture"
  />
</p>

**Engineering highlights**

- PostgreSQL-authoritative **multi-tenant architecture**
- **3 application roles** with **5 security clearance levels**
- **6 external connector families:** GitHub, Slack, Gmail, Google Drive, Dropbox, and Zendesk
- Secure ingestion using **Microsoft Presidio**, PII redaction, secret detection, classification, and pre-storage scrubbing
- **PostgreSQL + pgvector** retrieval with tenant, clearance, and metadata filtering
- **Groq** integration for LLM-assisted responses
- **Redis** for sessions, OTP state, and transient application state
- **Server-Sent Events** for observability and live connector activity
- OAuth and webhook integrations through **Nango**
- Fernet-based credential encryption
- Privacy deletion workflows and tenant-scoped audit records
- Dockerized frontend/backend/data infrastructure
- AWS infrastructure defined with **Pulumi**
- EC2, VPC, IAM, AWS Secrets Manager, CloudWatch, and encrypted EBS support
- **20 backend test files with approximately 121 tests**

The project inventory verifies the six integrations, five clearance levels, three roles, and the backend test coverage. :chatgpt-content-reference{index="0"}

#### Customer Churn Prediction

<p>

- Random Forest optimization using GridSearchCV
- Artificial Neural Network using TensorFlow/Keras
- SMOTE for class-imbalance handling
- Accuracy, precision, recall, F1, and confusion-matrix evaluation
- Interactive Streamlit prediction interface
